# 웹 트래픽 대시보드 · Vue + Vite

`dashboard-vue-vite`는 Vue 3, Vite, TypeScript, Nuxt UI와 Tailwind CSS 4로 만든 SPA입니다. 사전 생성한 정적 페이지에서 시작해 브라우저에서 로그인과 화면 전환을 처리합니다. 한국어·영어, 라이트·다크 테마, 일별 방문 추이와 기기별 비중을 지원합니다.

## 로컬에서 열기

Node.js **26.x**와 pnpm **10.34.9**를 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

[http://localhost:3333](http://localhost:3333)에서 공개 계정 **`demo@example.com` / `traffic-demo`**로 로그인합니다. 폼은 미리 채워져 있습니다. `/`는 로그인 여부에 따라 `/login`이나 `/dashboard`로 이동합니다. 같은 탭에서 새로고침하면 세션과 조회 기간이 유지됩니다. 로그아웃하면 대시보드 직접 접근이 차단됩니다. 세션은 브라우저에 저장되며 실제 회원 정보는 다루지 않습니다.

## 무엇을 비교할 수 있나요?

대시보드는 [2026년 9월의 방문 데이터](./src/data/traffic.json)를 [집계 함수](./src/data/traffic.ts)로 계산합니다. 기준일은 9월 30일입니다.

| 기간       | 총 방문 | 일평균 | 모바일 |     PC |
| ---------- | ------: | -----: | -----: | -----: |
| 7일 (기본) |  10,489 |  1,498 |  6,192 |  4,297 |
| 30일       |  36,639 |  1,221 | 21,532 | 15,107 |

두 기간 모두 최고 방문일은 **9월 29일, 1,790회**입니다. 900px 미만에서는 일별 추이와 기기 비중을 위아래로, 그 이상에서는 2:1 너비로 나란히 표시합니다.

1024px 이상에서는 사이드바를 접어 아이콘만 남길 수 있고, 작은 화면에서는 **메뉴 열기**로 서랍을 엽니다. 상위 메뉴를 펼치면 아래의 독립 화면으로 이동합니다.

| 상위 메뉴   | 하위 메뉴             | 할 수 있는 일                                         |
| ----------- | --------------------- | ----------------------------------------------------- |
| 회원 관리   | 회원 목록 · 가입 현황 | 이름·이메일 검색, 이용 정지·재개, 가입 월별 집계      |
| 매출 관리   | 주문 내역 · 매출 요약 | 주문 검색, 입금 확인, 결제 완료 주문의 월별 매출 조회 |
| 사이트 관리 | 기본 설정 · 공지 관리 | 사이트 이름·문의 이메일 저장, 공지 게시·초안 전환     |

관리 개요에서 입금 대기·정지 회원·미게시 공지 수를 누르면 해당 조건의 목록으로 이동합니다. 변경은 현재 데모 세션에만 적용되며 로그아웃하면 초기화됩니다.

방문 보고서 안의 **개요·차트·일별 내역**은 같은 기간을 사용합니다. 기간을 선택하면 요약과 차트, 최신 날짜순의 모바일·PC·합계 표가 함께 갱신됩니다. 표본을 처음 읽는 동안에는 실제 숫자·차트·표 행 위치에 맞는 스켈레톤이 표시됩니다.

## 페이지 번역 추가

Vue I18n 번역은 `locales/{ko,en}/` 아래 `common.yml`, `login.yml`, `dashboard.yml`, `not-found.yml`로 나뉩니다. 공통 문구는 `common.yml`에 두고, 페이지 전환 시 선택 언어의 해당 페이지 번역을 불러옵니다.

새 페이지에는 라우트 이름과 같은 YAML 파일을 두 언어에 추가합니다. 예를 들어 `billing.yml`에 `title`을 정의하고 템플릿에서 `$t('billing.title')`로 읽습니다. `{count}` 같은 보간 변수는 양쪽에 동일하게 둡니다. 라우트 정의와 정적 경로 예시는 [번역 추가 가이드](./locales/README.md)에 있습니다.

## 빌드와 검증

```sh
pnpm build                     # vite-ssg가 dist/에 HTML과 정적 자산을 생성
pnpm preview
pnpm typecheck
pnpm lint
pnpm exec vitest run           # 집계, 로그인, 라우팅, 페이지별 번역 검사
pnpm audit                     # 개발 의존성 포함
pnpm audit --prod              # 런타임 의존성만
```

[Nginx](./nginx.conf) 또는 [Netlify](./netlify.toml)에서 `dist/`를 제공합니다. 존재하지 않는 경로는 `404.html`로 처리하고, 공개 정적 HTML에는 로그인 후 리포트를 포함하지 않습니다.
